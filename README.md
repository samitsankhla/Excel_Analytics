## 📖 About The Project

Excel Analytics is a full-stack MERN application that allows users to upload Excel files, process spreadsheet data, and generate insightful analytics through interactive charts and visualizations.

The platform simplifies data analysis by transforming raw Excel data into meaningful reports, making it useful for students, researchers, analysts, and business users.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js (v18+)
* npm
* MongoDB (Local or Atlas)
* Git

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/samitsankhla/Excel_Analytics.git

cd excel-analytics
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## 🔑 Environment Variables

### Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
```

### Frontend (.env)

```env
VITE_API_URL=http://localhost:5000
```

---

## ▶️ Running the Application

### Start Backend

```bash
cd backend

npm run dev
```

or

```bash
npm start
```

### Start Frontend

```bash
cd frontend

npm run dev
```

Application URL:

```bash
http://localhost:5173
```

## 🐛 Troubleshooting

### MongoDB Connection Error

* Verify MongoDB is running
* Check MONGO_URI configuration
* Ensure Atlas IP access is enabled

### File Upload Issues

* Verify supported Excel formats
* Check upload size limits
* Confirm backend upload directory exists

### Chart Not Displaying

* Verify processed data exists
* Check browser console for errors
* Ensure chart library dependencies are installed
